# Продукты — закупка, готовка, остатки

PWA без сборки (HTML/CSS/JS). Все данные хранятся в `localStorage` браузера.

## Разделы

- **Закупка** — список продуктов с планом по граммам/штукам. В магазине нажимаете на продукт, указываете сколько взяли → остаток увеличивается, строка отмечается. «Новая закупка» снимает отметки.
- **Готовка** — нажимаете на продукт, указываете сколько использовали → остаток уменьшается.
- **Остатки** — все продукты с текущим остатком. Красным выделены закончившиеся, жёлтым — где остаток ≤ минимального. Здесь же добавление/редактирование продуктов (кнопка «+», нажатие на строку), экспорт/импорт JSON (меню «⋯»).

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте код в ветку `main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` сам задеплоит сайт при каждом пуше в `main`.
4. Откройте `https://<логин>.github.io/<репозиторий>/` на телефоне и добавьте на главный экран.

При изменении файлов увеличьте `VERSION` в `sw.js`, чтобы установленное приложение обновило кэш.

## Локальный запуск

Service Worker требует `http://`, поэтому откройте через любой статический сервер, например:

```
npx serve .
```
